# Xプロフィール用サイト

Xのbioに載せるための、1ページ構成のレスポンシブな自己紹介サイトです。依存関係なしのHTML/CSS/JavaScriptなので、そのままVercelなどの静的ホスティングにデプロイできます。

## 仕様

- 日本語 / 英語の切り替えボタン
- ヴィク勇をイメージした紫〜青のグラデーション
- 氷上を滑った跡をイメージした細い楕円トレイル
- スマホ・タブレット・PC対応
- CSSアニメーションなし、リンクのホバーのみで軽量

## Vercelへ公開する場合

このフォルダをGitHubリポジトリに置き、VercelでそのリポジトリをImportします。Framework Presetは「Other」、Build Commandは空欄、Output Directoryは `.` のままで公開できます。
